# Security policy

## Supported versions

Somen is currently in alpha. Security fixes are provided for the latest published prerelease only.

## Reporting a vulnerability

Please [report vulnerabilities privately through GitHub Security Advisories](https://github.com/Yusaku01/somen/security/advisories/new). Include the affected version, a way to reproduce the issue, and its potential impact. Please avoid opening a public issue before a fix is available.
